# iCost Analyzer

iCost Analyzer 是一个开源、第三方、非官方的 iCost 账单分析工具。将 iCost
导出的 Excel 账单拖入页面，就能查看收支、消费趋势和交易明细，适合在电脑上
回顾年度、月度、旅行或多币种消费。

本项目不隶属于 iCost 官方，也不代表 iCost 官方提供服务。工具采用本地优先
的方式：账单在当前浏览器页面内解析，无需账号，不会上传到服务器。

## 可以做什么

- **查看收支**：总支出、总收入、净结余、平均支出、最大单笔支出及报销、退款
  相关金额。
- **回顾消费**：月度趋势与复盘、每日支出热力图、每日收支，以及分类、账户、
  标签、币种和星期分布。
- **筛选账单**：按时间、交易类型、币种、账本、账户、分类、标签和关键词
  查找，也可以排除指定标签；图表和汇总表支持联动查看。
- **分析多币种消费**：手动设置汇率，统一折算成人民币，明细中保留原币金额。
- **借助 Agent 分析**：在兼容的浏览器中手动授权，让 Agent 查询汇总、分组
  和期间比较结果。
- **切换外观**：支持浅色、深色和跟随系统主题。

## 开始使用

1. 在 iCost 中导出 `.xlsx` 或 `.xls` 格式的 Excel 账单。
2. 打开 iCost Analyzer 页面，将文件拖入页面任意位置，或点击上传区域选择
   文件。大账单可能需要稍等片刻。
3. 查看指标、图表和明细，按需要调整筛选条件。
4. 如果包含外币，在“汇率设置”中检查并调整折算汇率。
5. 分析另一份账单时，直接拖入或选择新文件；成功导入后会替换当前账单。

图表会在滚动到附近时加载。调整筛选后，屏幕内的图表更新；再次滚动到其他
图表时，会显示最新结果。各年度热力图仍使用同一筛选范围的颜色尺度。

账单仅保留在当前页面会话中。刷新或关闭页面后，需要重新导入；替换文件后，
如需查看旧账单，也需要重新导入。

## 导入要求

只读取 Excel 的**第一张工作表**。每笔记录必须有有效日期和数字金额；日期
无效、金额为空或不是数字的行会被跳过，页面会提示跳过的行数。

## 筛选与金额说明

调整筛选后，明细回到第 1 页，分类占比图返回一级分类。修改明细排序或每页
条数也会回到第 1 页。重置筛选会保留排序和每页条数；成功更换账单后，排序
恢复默认，每页条数继续保留。

日期按浏览器本地时间计算，自定义区间和年份筛选包含起止两天。

<details>
<summary>“今年”和“近 N 个月”如何计算？</summary>

“今年”从本年第一天起算，截至当前分析时刻。“近 N 个月”从当前分析时刻按
日历月份回溯，保留时分秒；月末遇到不存在的日期会顺延到下个月。

这些快捷范围在导入账单、修改筛选或更新有效汇率时重新计算，页面不会随时间
自动推进范围。页面统计与 Agent 查询使用同一次分析的时间基准。

</details>

- **汇率**：人民币（CNY）固定为 1，外币按“1 单位外币兑换多少人民币”填写。
  内置汇率是静态参考值，不是实时行情。
- **无效输入**：汇率留空、非数字或不大于 0 时，会提示无效并继续使用之前的
  有效汇率。点击“恢复内置汇率”可重置。
- **缺少汇率**：相关交易仍计入笔数，人民币折算金额按 0 计入，因此合计并不
  完整。请补充有效汇率后再查看结果。
- **标签合计**：同一笔支出可能属于多个标签，不能将各标签金额相加当作总支出。

## 与 Agent 一起分析

这项功能需要支持 WebMCP 页面工具的 Agent 浏览器。是否可用，请以页面提示
及实际工具发现、调用结果为准；仅向 Agent 发送网页链接，不能让它读取你
设备上的账单。

1. 在兼容的 Agent 浏览器中打开本站，**亲自在同一个页面上传账单**，调整
   筛选和汇率。
2. 在“Agent 分析”区域点击“允许 Agent 分析”，再向 Agent 提问，例如：
   “按当前筛选汇总支出，并列出支出最高的五个分类”。
3. 需要停止时点击“停止 Agent 分析”。开始更换文件或刷新页面后，授权自动
   关闭；每份新账单都需要重新手动开启。

Agent 只能查询账单概况、汇总、分组和指定日期的期间比较，不能读取逐笔交易，
也不能修改页面筛选或汇率。查询默认遵循当前筛选；分析全账单需要明确指定。
比较两个期间时，指定日期会替代页面日期筛选，其他筛选仍然生效。缺少有效
汇率的查询结果会标记为“部分合计”，并列出受影响的币种、笔数和原币金额。

## 隐私说明

- 账单文件在浏览器本地解析，本站不会接收或保存账单，也没有账号系统或遥测。
- 浏览器存储只保存主题偏好，不保存账单数据或 Agent 授权。
- 开启 Agent 分析后，工具返回的**汇总结果、筛选条件（包括关键词）及分类、
  账户等分组名称会进入你所使用的 Agent 会话**。本站不替 Agent 服务商承诺
  其数据保留方式。停止授权后，页面工具不再返回账单统计。
